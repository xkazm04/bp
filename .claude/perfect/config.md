# /perfect overlay for bp

Vault: none configured, so the loop keeps state in `<repo>/.perfect/Perfect/` (git-ignored).
Context ids for commit scopes are the `id` fields in `context-map.json` (e.g. `app-shell`).

## Gates

- always: `npm run typecheck` and every `check:*` script plus `validate:structure` (all run in seconds; baseline 2026-10-12 is all green), then `npm run build` (Director only - concurrent builds in one tree clash on `.next/`).
- when a variant CSS source changed: `npm run check:variant-copies` must stay green (copies are generated, see Class C).
- when `src/app/globals.css` or a theme token changed: `npm run check:tokens`.
- when `src/engine/chrome.ts`, `rail.css` or `timeline.css` changed: `npm run check:chrome` and `npm run check:timeline-size`.
- visual (any wave touching `src/engine/**`, `src/components/**`, variant or global CSS): `npm run build && npx next start -p 3123`, then `python scripts/shots.py http://localhost:3123 <scratch-outdir>` (both themes, three widths, page errors, 12 px floor) plus a short Playwright probe of each interaction the wave changed. Read the builders' "needs a browser" lists as the probe agenda.
- slow: `python scripts/perf.py` (needs a running server) - not part of the nightly gate.
- builder: `npm run typecheck` plus the `check:*` scripts that cover files in the write set. Never `npm run build` and never `npm run dev` (one tree, one `.next/`).

## Repo law

- Read `docs/blueprint-ui.md` in full first; it is the build contract. `docs/standard/app-structure-v3.md` governs data shapes.
- Owner taste (non-negotiable): no galaxy/star/cosmic metaphors; L0 behaves like a map (few large labelled sections, nested levels on zoom); nothing readable under 12 px on screen, body 14 px; left-to-right chronology; spatial stability (a lens/filter/time change changes what places say, never where they are); lenses never recolour nodes - they differ by shape, icons, indicators, content and density; General is the composition of all lenses; blue/white primary palette in both dark and light themes.
- Performance rules: the camera never touches React state; draw only when dirty; cache static geometry/rasters; allocate nothing in the frame loop; React re-renders only on discrete changes via the small external store (`src/engine/store.ts`) with selectors.
- Colours/sizes come from tokens in `src/app/globals.css` (both themes must have the token - `check:tokens`). Collapsed chrome sizes live only in `src/engine/chrome.ts`.
- Motion: `motion/react` for DOM; reduced motion makes entrances instant.
- No new runtime dependencies. Localhost-only API routes stay localhost-only.
- Reuse before building: grep `src/components`, `src/lib/model`, `src/engine` for an existing mechanism first.
- Out of scope walls: `.contest/`, `prototypes/`, `.spark/`, `.next/`, `bp.products.local.json`, any other repo.

## Skill improvement log
- 2026-10-12 (nightly, 7 waves, 52 directions over 11 contexts): scouting ALL contexts up front (2 parallel batches) and grouping waves by write set kept 3 builders busy with zero collisions; Engine.ts was the contention point and had to be serialised across 5 waves - put Engine.ts-touching directions in one lot per wave.
- Builder "needs a browser" lists are not optional: the Director's `python scripts/shots.py` + small Playwright probes against `next start -p 3123` caught 3 regressions/defects gates could not (ghosted then vanished tile names from an LOD crossfade, a trackpad classifier misreading Chromium's synthetic wheelDeltaY, a header summary still clipping). Run shots after every wave that touches render or chrome.
- A "fix" to a visual regression must be re-shot at the SAME view: the first ghosting fix (sequential fade) produced blank tiles at rest mid-band - verify at the exact viewport the bug was seen.
- Hypothesis-framed directions work: dev-lens-dense-canvas was honestly refuted by its builder with evidence (dense lenses already show 4 parts) instead of shipping redundant chrome.
- 2026-10-13: the four bullets above were applied to the shared method as perfect 2.8.0 (`/perfect unattended`, hot-file lots, importer-owning moves, the visual integration gate); this overlay gained `## Gates > visual`.
