Four ways to draw Larkspur

Each variant reads the same mock product (6 domains, 20 modules, 122 features) and must do the same job, so you can compare the shape and identity directly.

  1. A
    Cyanotype

    An architect's floor plan. Domains are zones, modules are rooms and features are fixtures. Drafting line styles show status, lenses switch between drawing sheets, and revision clouds mark AI work that needs review.

  2. B
    Orbit

    A star chart with the product at its core and rings for domains and modules. Features are stars with coronas for their three dimensions. In the dimension lenses, finished work moves inward and unfinished work drifts out.

  3. C
    Atlas

    A practical left-to-right tree of cards on an infinite canvas. Detail grows as you zoom, each card has a 12-cell facet barcode, and there is a minimap and a review queue.

  4. D
    Periodic

    A periodic table of features. Modules are columns, domains are blocks, and each feature is an element tile. The same tiles rearrange by module, by status or by release.
